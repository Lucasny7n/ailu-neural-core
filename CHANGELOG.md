# Changelog

- Created initial Ailu Neural Core project.
- Added Tauri v2, React, TypeScript, Vite, React Three Fiber and Zustand stack.
- Added navigable 3D neural space with core, nodes, connections and particles.

- Added Actions, Providers, Diagnostics and Settings views.
