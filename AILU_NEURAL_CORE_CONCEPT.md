# Ailu Neural Core Concept

Ailu Neural Core is a navigable 3D visual brain for operating a local Linux system through AI, with the human operator in control.

The operator gives intent. AI workers plan. The Approval Layer authorizes. The System Agent executes only after explicit confirmation. The neural graph records relationships between system areas, actions, diagnostics and future memory episodes.

The interface should feel like entering the mind of the local assistant:

- the Ailu core is the central brain;
- Arch/Hyprland is the body;
- system modules are neural nodes;
- logs, services and hardware are connected pathways;
- actions create new memory edges;
- every real command is visible before execution.

This MVP focuses on foundation: 3D navigation, structured planning, local diagnostics, approval and persistence. It does not claim autonomous repair, background system control, real Graphiti integration or multi-agent execution yet.
